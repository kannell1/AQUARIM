# AQUARIM — сайт рыбного ресторана

Готовый Next.js-проект по макету из переписки: **первые два блока**, то есть главный экран вместе с шапкой сайта и секция «История рыбного искушения». Это не вся длинная страница: остальные блоки будем добавлять позже.

Технологии: **Next.js 15 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS 4**. Стили расположены прямо в `className` компонентов. `app/globals.css` используется только для подключения Tailwind CSS и шрифтов.

Используются **оригинальные изображения, иконки и шрифты** из приложенных архивов:

- `public/images/shrimp-fork.png` — креветка на вилке (главный экран);
- `public/images/chef-aquarium.png` — шеф-повар на фоне аквариума (история);
- `public/icons/cart.svg`, `fish.svg`, `delivery.svg` — иконки;
- `public/fonts/` — Gilroy и TRIAL Oceanic;
- остальные изображения из архива тоже сохранены в `public/images/` для следующих блоков.

## 1. Как открыть проект и запустить

1. Установите **Node.js** (лучше актуальную LTS 22.x) с https://nodejs.org/ — npm устанавливается вместе с ним.
2. Скачайте ZIP проекта и **распакуйте** в удобную папку.
3. Откройте папку `aquarim-next` в **VS Code**: **File → Open Folder...**.
4. В VS Code выберите **Terminal → New Terminal**.
5. Выполните команды:

```bash
npm install
npm run dev
```

6. Откройте в браузере **http://localhost:3000**.
7. Остановить сервер: **Ctrl+C** в терминале.

> Нужно, чтобы команды запускались **из папки `aquarim-next`**, где лежит `package.json`.

### Где меняются стили?

Открываем, например, `components/HeroSection.tsx` и меняем Tailwind-классы прямо у элемента:

```tsx
<a className="bg-[#E9663D] text-[#E8EDFF] px-10 py-5">Меню</a>
```

Цвета взяты из макета: тёмно-синий `#011845`, приглушённый синий `#496192`, светлый текст `#E8EDFF`, оранжевый `#E9663D`. `app/globals.css` не содержит индивидуальных стилей блоков.

## 3. Как сохранить проект на GitHub (с коммитом)

1. Создайте бесплатный аккаунт на https://github.com/ (если его ещё нет).
2. На GitHub нажмите **New repository** и назовите, например, `aquarim-next`. Не нужно включать README при создании репозитория, потому что он уже есть.
3. В терминале VS Code в папке проекта выполните:

```bash
git init
git add .
git commit -m "Add AQUARIM header, hero and history sections"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/aquarim-next.git
git push -u origin main
```

Замените `ВАШ-ЛОГИН` на свой ник GitHub.

Если Git пишет, что у вас не настроены имя или email, один раз выполните (со своими данными):

```bash
git config --global user.name "Имя Фамилия"
git config --global user.email "email@example.com"
```

Затем повторите `git commit` и `git push`. Для авторизации GitHub используйте браузер/VS Code или Git Credential Manager (пароль аккаунта для `git push` по HTTPS не используется).

В следующий раз для нового коммита:

```bash
git add .
git commit -m "Update AQUARIM website"
git push
```

## 4. Как опубликовать сайт на Vercel

1. Откройте https://vercel.com/ и войдите через GitHub.
2. Нажмите **Add New → Project**.
3. Выберите репозиторий **aquarim-next** и нажмите **Import**.
4. Проверьте, что Framework Preset — **Next.js**, Root Directory — `./`.
5. Нажмите **Deploy** и дождитесь завершения.
6. Vercel выдаст ссылку на опубликованный сайт. Следующие пуши в `main` обычно автоматически запускают новое развёртывание.

## Важно

- Пока сделаны **только первые два блока** по исходному запросу. Пункты меню «Меню», «Доставка и оплата», «Контакты» и кнопка «Меню» пока ведут к якорям будущих разделов — после добавления остальных блоков заработает прокрутка к ним.
- Кнопка «Узнать больше» пока возвращает к началу страницы, её поведение можно связать с отдельной страницей или расширенным описанием на следующем этапе.
- **Oceanic TRIAL** — пробная версия шрифта из предоставленного архива. Перед публичным коммерческим запуском проверьте лицензионные условия или замените его на приобретённую лицензионную версию.
- Папку `node_modules` и результат сборки `.next` в GitHub отправлять не нужно: они исключены в `.gitignore`.
